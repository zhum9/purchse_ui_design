# Skill: Enterprise Table

## 目标

为采购订单、履约工作台、SAP监控、对账、退货/冲销记录等页面提供高可用企业级表格规范。

## 表格原则

表格是采购执行中心最核心的信息载体。

优先保证：

- 扫描效率
- 列稳定性
- 筛选效率
- 状态可读性
- 数值对齐
- 操作安全

不要为了“现代感”用大量卡片替代表格。

## 技术建议

简单表格：

- Ant Design Table

复杂表格：

- TanStack Table 管理状态/逻辑
- Ant Design 负责视觉

复杂能力包括：

- 多列排序
- 列显隐
- 固定列
- 大数据分页
- 虚拟滚动
- 行选择
- 分组
- 聚合
- 用户自定义列

## 列设计

左侧优先：

- 单号
- 行号
- 供应商
- 采购内容

中间：

- 数量/金额
- 日期
- 场景
- 组织

右侧：

- 状态
- 操作

操作列建议固定右侧。

## 数值格式

数量：

```text
1,000.00 吨
```

金额：

```text
¥1,200,000.00
```

百分比：

```text
60%
```

数值列右对齐。

单位尽量紧邻数值。

## 状态列

状态使用 Tag/Badge + 文案。

不要只用颜色点。

例如：

- 部分收货
- 服务验收中
- 已完成
- SAP异常

## 查询区

默认规则：

- 常用筛选 4~6 个
- 低频条件放“更多筛选”
- 提供一键重置
- 允许 Enter 查询
- 搜索后保留条件

采购履约推荐：

- SAP PO
- 供应商
- 采购内容
- 执行场景
- 状态
- 日期

## 快速筛选

适合使用 Tabs/Segmented：

- 全部
- 待执行
- 部分执行
- 即将到期
- 异常

数量展示可用轻量 count，不要大型 KPI 卡。

## 行操作

高频操作直接展示：

- 收货
- 服务验收
- 查看

低频操作放 More：

- 退货
- 冲销
- 查看SAP信息
- 查看日志

危险动作不得与普通操作视觉等价。

## 空状态

空状态文案要解释下一步：

推荐：
> 当前没有待执行的采购订单行。

可提供：
- 清除筛选
- 返回全部

## 加载状态

表格加载时：

- 保留页面整体结构
- 不闪烁布局
- 使用 Skeleton 或 Table loading

## 错误状态

接口失败时不要直接清空列表。

显示：

- 数据加载失败
- 重试按钮
- 保留已知筛选条件

## 批量操作

仅在业务明确允许时提供。

严禁默认提供批量：

- 冲销
- 退货
- 强制关闭

## 大数据

当列表可能达到万级以上：

- 服务端分页
- 服务端排序
- 服务端筛选
- 避免一次性加载全部数据

## 表格密度

默认使用中等或紧凑尺寸。

采购执行类后台不使用过宽行高。

## 输出前检查

1. 单号列是否容易定位？
2. 数值是否右对齐并带单位？
3. 状态是否有文本？
4. 操作列是否固定？
5. 危险操作是否隐藏在二级操作中？
6. 查询条件是否过多？
