# Skill: Procurement UI

## 目标

规范采购执行中心的核心业务页面和交互。任何采购相关页面生成前，必须先理解业务语义，再选择组件和布局。

## 核心业务原则

### 1. 采购订单是执行主线

支持：

- 合同 → 采购订单
- 采购申请 → 采购订单
- 寻源结果 → 采购订单
- 直接采购订单
- 外部系统 / SAP 下发采购订单

禁止把“合同”设计成所有采购的必经节点。

### 2. 采购订单行是最小执行单元

同一张 PO 可以包含：

- 库存物料
- 无物料号采购
- 服务
- 限额服务
- 固定资产
- 外协等

页面操作、表单字段和状态必须允许逐行不同。

### 3. 物料号不是全局必填

必须支持：

- 有物料号
- 无物料号 + 物料组 + 短文本
- 服务
- 限额服务

禁止在全局表单中把物料号设为必填。

### 4. 服务采购不是普通收货

服务类操作文案使用：

- 服务验收
- 执行确认
- 服务确认

不要显示：

- 库存地点
- 批次
- 序列号

除非具体业务规则明确要求。

### 5. 退货与冲销必须分开

采购退货：

> 原收货业务正确，后续真实退回供应商。

收货冲销：

> 原收货操作错误，需要撤销原业务影响。

禁止把两者合并成一个“退货/冲销”按钮。

## 采购订单列表

推荐字段：

- SAP采购订单号
- 业务订单号（如有）
- 供应商
- 采购组织
- 采购组
- 订单日期
- 金额
- 行数
- 履约状态
- SAP同步状态
- 更新时间

快速筛选：

- 全部
- 待执行
- 部分执行
- 执行完成
- 异常

## 采购订单详情

顶部展示：

- PO号
- 供应商
- 采购组织
- 订单金额
- 订单日期
- 当前状态

订单行表格必须包含：

- 行号
- 执行类型
- 采购内容
- 物料/物料组
- 订单量/额度
- 已执行
- 剩余
- 状态
- 操作

操作根据场景显示：

- 收货
- 服务验收
- 执行确认
- 查看

## 采购履约工作台

这是系统核心页。

列表必须能够混合展示多种执行场景。

推荐字段：

- SAP PO
- Item
- 供应商
- 采购内容
- 执行类型
- 订单量/额度
- 已执行
- 剩余
- 计划日期
- 状态
- 操作

不要拆成大量独立菜单：

- 物料收货
- 服务收货
- 无物料收货

统一入口，动态动作。

## 库存物料收货

必须展示：

- PO / Item
- 物料
- 供应商
- 订单数量
- 已收数量
- 剩余数量

典型输入：

- 本次收货数量
- 收货日期
- 过账日期
- 工厂
- 库存地点
- 批次（条件）
- 供应商批号
- 生产日期
- 有效期
- 送货单号
- 附件
- 备注

## 无物料号采购收货

显示：

- 采购描述
- 物料组
- 数量
- 单位
- 已执行 / 剩余

隐藏：

- 物料号选择器
- 批次
- 序列号

除非规则要求。

## 服务验收

必须突出：

- 服务名称
- 服务期间
- 订单金额
- 已验收金额
- 剩余金额

典型输入：

- 服务开始日期
- 服务结束日期
- 本次完成数量
- 单位
- 本次确认金额
- 验收结果
- 服务完成说明
- 验收意见
- 成果附件
- 验收报告
- 工作量清单
- 验收人

## 限额服务

页面主轴是额度，不是库存数量。

突出：

- Expected Value
- Overall Limit
- 累计执行
- 剩余额度
- 本次执行后金额

## 采购退货

必须关联原收货记录。

显示：

- 原PO / Item
- 原收货单
- 原收货数量
- 历史已退
- 当前可退

输入：

- 本次退货数量
- 退货原因
- 退货日期
- 库存地点
- 批次
- 是否补货
- 附件
- 备注

## 收货冲销

页面显著提示：

> 冲销用于撤销错误的收货操作，不等同于采购退货。

显示：

- 原PO / Item
- 原收货单
- 原收货数量
- SAP物料凭证
- 原收货日期

输入：

- 冲销原因
- 冲销日期
- 过账日期
- 附件
- 备注

确认动作必须二次确认。

## 单据流

单据流用于表达业务事实链，不是 BPMN 编辑器。

推荐节点：

- 合同（可选）
- PO
- ASN（可选）
- 收货
- 服务验收
- 冲销
- 退货
- 退货冲销

节点展示：

- 单号
- 日期时间
- 数量/金额
- 状态

节点可点击查看详情。

## 业务状态文案

优先业务语言：

- 待执行
- 部分收货
- 已全部收货
- 部分验收
- 已完成
- 已退货
- 已冲销
- SAP处理中
- SAP异常

禁止直接把 SAP 技术码当主状态文案。
